# tcm-frontend

React (JavaScript) + Vite frontend for the Training Center Management
Application, using Tailwind CSS and shadcn/ui.

See the root [`README.md`](../README.md) for how to run this alongside the
backend, and [`docs/PLAN.md`](../docs/PLAN.md) for architecture and
conventions.

## Scripts

```bash
npm install
npm run dev      # start the dev server
npm run build    # production build to dist/
npm run lint     # oxlint
npm run preview  # preview the production build locally
```
